베이커 랩 노트 — 웹앱(설치형) 올리는 방법

이 폴더 전체를 인터넷 주소가 있는 곳에 올리면, 누구나 링크로 들어와
휴대폰 홈 화면에 앱처럼 설치해 쓸 수 있어요. (앱스토어 심사·수수료 없음)

[가장 쉬운 방법: Netlify Drop, 무료]
1. PC에서 https://app.netlify.com/drop 접속 (무료 회원가입)
2. 압축을 푼 이 폴더(webapp)를 통째로 끌어다 놓기
3. 몇 초 뒤 나오는 주소(예: https://이름.netlify.app)를 열면 끝
4. 사이트 이름 바꾸기: Site configuration → Change site name

[휴대폰에 설치]
- 아이폰(Safari): 주소 열기 → 공유 버튼 → "홈 화면에 추가"
- 안드로이드(Chrome): 주소 열기 → 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
- 한 번 열면 인터넷이 없어도 열려요.

[새 버전 올리기]
- index.html을 바꾼 뒤 sw.js 첫 줄의 VERSION 글자를 바꾸고 다시 끌어다 놓기

      비용 정보, 정부 지원 안내, 음성 질문·읽어주기, AI 비서의 '앱 안 지식' 답변
- 아직: 회원가입·여러 기기 동기화(기록은 그 기기에만 저장 → 백업 파일 사용),
